# NowPay Go v0.3.0 — Postman alignment

**Release date:** 2026-06-20

### Install

```bash
go get github.com/muxover/nowpay-go@v0.3.0
```

---

## Summary

v0.3.0 realigns the SDK with the official NOWPayments Postman collection. It fixes a base-URL bug that broke every request, corrects the payout and subscription endpoints, and adds full coverage for conversions, custody (customer management), and fiat payouts. This release contains breaking changes.

---

## What's included

### Fixed

- Base URL no longer duplicates the version segment (`/v1/v1/...`).
- Mass payouts: `Create` sends the `withdrawals` array to `POST /payout`; `Verify` is a `POST` with a `verification_code`; `Get` and `List` decode the real response envelopes.
- Payments: `List` decodes the `{ "data": [...] }` envelope; payment fields match the API (`expiration_estimate_date`, `invoice_id`, `network`, `type`, `payment_extra_ids`).
- IDs and amounts decode from both numbers and strings via `models.FlexInt` / `models.FlexFloat`.

### Conversions

- `Create`, `Get`, `List`.

### Customers (Custody)

- `Create`, `Balance`, `List`, `Payments`, `Transfers`, `GetTransfer`, `Transfer`, `Deposit`, `WriteOff`, `DepositWithPayment`.

### Fiat payouts

- `Providers`, `FiatCurrencies`, `CryptoCurrencies`, `PaymentMethods`, `CreateAccount`, `Accounts`, `Request`, `List`.

### Breaking changes

- Subscriptions rewritten to the plan-based `/subscriptions` model: `CreatePlan`, `UpdatePlan`, `GetPlan`, `ListPlans`, `Create`, `Get`, `List`, `Delete`.
- `Payouts.Create` takes `*CreatePayoutRequest` and returns `*PayoutBatch`; `Get` returns `[]Payout`; `Verify` takes a code; `BatchCreate` removed.
- Removed endpoints absent from the API: `Payments.GetFlow`, `Payments.Refund`, `Currencies.Available`, `Invoices.Get`.
