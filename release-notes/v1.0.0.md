# NowPay Go v1.0.0 — Complete NOWPayments SDK

**Release date:** 2026-10-08

### Install

```bash
go get github.com/muxover/nowpay-go@v1.0.0
```

---

## Summary

NowPay Go v1.0.0 is the first complete release of the Go SDK for NOWPayments. Every method in it was run against the production NOWPayments API and is tested against both the documented and the real responses. It replaces all v0.x versions, which are retracted.

---

## What's included

### API coverage

- Payments, invoices, currencies, and estimates.
- Recurring payments: plans and email subscriptions.
- Custody customers: create, balance, list, payments, transfers, and deposit with a payment.
- Account balance, payout listing, address validation, withdrawal minimums, and fees.
- Conversion listing, and fiat-payout providers, currencies, payment methods, accounts, and payouts.

### Webhooks

- IPN signature checks that match how NOWPayments signs callbacks, including text with `&`, `<`, `>`, and non-ASCII characters.
- Typed payment events, with the event type derived from the payment status.

### Reliability

- `APIError` with the status, NOWPayments error code, and message, matched by sentinel errors.
- Optional retries that never repeat a `POST` after a server error, so a payment is not created twice.
- IDs and amounts decode whether the API sends them as numbers or strings.
- No dependencies outside the standard library. Go 1.21 or later.
